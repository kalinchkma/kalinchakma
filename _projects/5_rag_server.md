_Professional project at Mediusware Ltd._

The server behind an AI-powered mobile app:

- A **retrieval-augmented generation (RAG)** pipeline that grounds answers in app data
- **Vector search** to retrieve semantically relevant context
- **LLM integration** for generating responses
- **Serverless functions** for parts of the workload that scale independently

### Tech

`RAG` · `Vector DB` · `LLM` · `Serverless`
