**Geko** is a project scaffold for Go that gives you a production-ready starting point for server-native applications.

### What it includes

- **Routing:** a ready-to-use HTTP routing layer
- **ORM:** a database layer wired in from the start
- **Mail:** built-in support for sending email
- **Structure:** an opinionated layout that keeps large Go services organised as they grow

### Tech

`Go` · `ORM` · `HTTP` · `SMTP`
