_Professional project._

I designed the architecture for a car-auction platform built as a set of microservices.

- **Service communication** over **gRPC**
- **API and WebSocket servers** for real-time bidding updates
- A **PDF parsing service** for vehicle documents
- **Redis** caching and **PostgreSQL** storage, with a **CDN** for media

### Tech

`Microservices` · `gRPC` · `WebSockets` · `Redis` · `PostgreSQL` · `CDN`
